# Chat Usage

This app is a simple chat demo.

## Start the app

1. Start backend:
   - `cd backend`
   - `./gradlew.bat bootRun`
2. Start frontend:
   - `cd frontend`
   - `npm install`
   - `npm start`

Open `http://localhost:3000`.

## Use the chat

1. Type your message in the chat box.
2. Press `Enter` or click `Send`.
3. Read the agent response.

Try messages like:
- `add 12 and 8`
- `what is your return policy`
