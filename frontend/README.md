# Clothes Store Agent - React Frontend

This is the React frontend for the Clothes Store Agent application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Make sure the backend is running on port 8081

3. Start the React development server:
```bash
npm start
```

The app will open at http://localhost:3000 and proxy API calls to the backend at http://localhost:8081.

## Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs tests

## Features

- **Schema Panel**: View database schema, foreign keys, and sample values
- **Query Panel**: Execute custom SQL queries with parameters
- **NLQ Panel**: Convert natural language to SQL queries
- **Result Panel**: View query execution results
